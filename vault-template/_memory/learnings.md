# Cortex — Global Operating Lessons

> The **learning loop**. Captures durable *operating lessons* (a preference, pattern, or gotcha — "how to operate") — never session transcripts, never facts that belong in a note. Facts about a person/initiative go inline in that note's "Lessons / preferences" section, tagged with their scope. This file holds only **global**, cross-cutting lessons.
>
> Written via `/remember`. **Capped** (keep this short) and **pruned/merged** — when it grows, consolidate; do not just append. Read at the start of every briefing.

## How an entry looks

```
- [global] (2026-05-29) Lead status updates with metrics, not activity. #comms
- [global] (2026-05-29) Decisions need a written rationale before they're shared up. #decisions
```

Format: `- [scope] (date) lesson. #tag` — one line each, scope is `global` here. Dedupe before adding.
